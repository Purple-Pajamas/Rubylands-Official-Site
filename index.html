Welcome to the Rubylands!

This is the official site for the Rubylands Extension for Minecraft, an open source mod which overhauls the game with new blocks, items, features and more.

Whether you're here for the main branch or any potential forks, you'll find all sorts of official, curated Rubylands content here.

Do note that this website is under heavy construction, so many things will be unfinished!
